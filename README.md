# 🚗 Smart Parking Lot System

A full-stack web application designed to simplify and automate parking lot management in urban environments.  
The system handles vehicle check-ins and check-outs, smart parking space allocation, real-time availability tracking, and automatic fee calculation—all in one place.

Built using **Node.js, Express, SQLite, and React**, this project focuses on performance, concurrency safety, and real-world usability.

---

## 🌟 Features

### Core Functionality
- 🚦 **Vehicle Check-In & Check-Out**  
  Automatically records entry and exit times with instant space assignment.

- 🅿️ **Smart Spot Allocation**  
  Uses a first-fit algorithm to efficiently assign available parking spaces.

- 📊 **Real-Time Availability**  
  Live updates showing available spaces across all parking floors.

- 💰 **Automatic Fee Calculation**  
  Fees calculated based on parking duration and vehicle type, with daily caps.

- 🕒 **Vehicle Parking History**  
  Complete check-in/check-out history for every vehicle.

- 📈 **Dashboard Analytics**  
  Real-time insights into occupancy, revenue, and floor-wise parking status.

---

## 🧠 System Capabilities

- Supports multiple vehicle types: **Motorcycle, Car, SUV, Bus**
- Manages **multi-floor parking lots**
- Handles **concurrent check-ins and check-outs**
- Prevents double booking with locking mechanisms
- Tracks occupancy rates and revenue metrics
